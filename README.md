# Cosmic Catfish Project 

What if the key to surviving in space was... dating aliens?

Cosmic Catfish is an interactive, space-themed dating game that combines humor, exploration, and education. Players take on the challenge of connecting with aliens from different planets to gather information and uncover the truth about their worlds.

The catch? Our existing planetary data isn't entirely accurate, and it's up to you to figure out what's right. By matching and chatting with aliens, players can discover new facts, correct misinformation, and learn more about the planets in our solar system.

We wanted to make learning about space feel less like studying and more like an adventure. By combining the familiar experience of dating apps with planetary exploration, Cosmic Catfish turns conversations into discoveries.

## About 
Cosmic Catfish is an interactive, space-themed dating game that combines humor, education, and planetary exploration. Players match and chat with aliens from different planets to gather information and correct inaccurate planetary data.

Our goal was to make learning about space more engaging by turning research and discovery into a fun, interactive experience. The game also connects to the hackathon's space survivability theme by highlighting the importance of accurate information when exploring unfamiliar environments.

### Tools and Technologies
We built Cosmic Catfish using React, JavaScript, Vite, CSS, React Router, with GitHub for collaboration and version control.

Our project started with the standard Vite React boilerplate, which we customized to create our game.

### AI Usage Disclosure
We used AI primarily as a learning and debugging tool to better understand concepts, troubleshoot errors, and improve our code. AI also assisted with some styling and game-logic components, which we adapted and integrated into our project.

The concept, creative direction, and overall game experience were developed collaboratively by our team.

## Prerequisites
To build and run Cosmic Catfish locally, you'll need:

 - Node.js and npm – To install dependencies and run the application.
 - Git – To clone the repository from GitHub.
 - VS Code (recommended) – To view and edit the source code.
 - A modern web browser – Such as Chrome, Firefox, or Edge.

## Build from source
Follow these steps to run Cosmic Catfish locally:

 ### 1. Clone the repository
 Open your terminal and run:
 **git clone <https://github.com/cstaszak1/cosmicCatfish>**

 ### 2. Navigate to the project folder
 Make sure you're in the directory containing package.json.
 **cd cosmic-catfish**
 **cd CosmicCatfish/cosmic-catfish**

 ### 3. Install dependencies
 **npm install**

 ### 4. Start the development server
 **npm run dev**

 ### 5. Open the application
 Open the local URL displayed in your terminal (typically http://localhost:5173/) to start playing!
  
## Production Build
To create a production-ready build, run:

**npm run build**

This generates a dist folder containing the compiled application.

To preview the production locally, run:

**npm run preview**
